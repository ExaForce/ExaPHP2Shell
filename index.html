ExaPHP2Shell

CVE-2026-109618 / 109619 exposure check

A defensive, non-exploit exposure check for the two critical PHP core RCEs nicknamed PHP2Shell. It reads a target's PHP version from response banners and compares it against the fixed releases. No memory corruption is attempted and no payload is sent.

Backend settings

With a backend set, Scan reads the live banner and renders a verdict automatically. Without one, Scan tries a best-effort browser request and otherwise falls back to the assisted command below. The endpoint is stored only in this browser.

Confirm by package changelog, not the version string: distros backport without bumping it (rpm -q --changelog php-fpm | grep CVE-2026-10961).

If vulnerable

  • Patch to the fixed release for your branch, then restart workers: a patched file on disk does not protect a running worker.
  • Interim only: block multipart/form-data on routes that don't need uploads, set session.upload_progress.enabled=0, keep session.use_strict_mode=1, and on PHP 8.5 set fatal_error_backtraces=0. Config alone is not a full fix.
  • EOL branches get no upstream fix: take a vendor/source backport or upgrade; isolate un-patchable hosts.
Defensive tooling. Reads version banners and compares to published fixed releases; it does not attempt memory corruption or send payloads.
Verdicts are advisory. Only scan systems you are authorized to assess.
